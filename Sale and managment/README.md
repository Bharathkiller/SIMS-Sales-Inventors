# Sales & Inventory Management System (SIMS)

A browser-based Sales and Inventory Management System built with HTML, CSS, and JavaScript.

## Live features

- Product creation, editing, and deletion
- Inventory adjustments with low-stock and out-of-stock status
- Invoice creation that deducts stock automatically
- User management
- Dashboard, sales, inventory, and activity reports
- Responsive interface for desktop and mobile devices

## Run locally

Open `index.html` in a modern web browser.

## Publish with GitHub Pages

1. Upload the complete project to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Set the source to **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder.
5. Save. GitHub will show the published website URL once deployment finishes.

## Data storage note

This version stores data in the browser's local storage. Each browser/device has separate data. A backend database is required for shared multi-user data.
